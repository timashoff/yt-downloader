# Universal Downloader

🌍 **Языки**: [🇺🇸 English](README.md) | [**🇷🇺 Русский**](README.ru.md)

Быстрый CLI инструмент для скачивания аудио и видео с YouTube и 1000+ других сайтов, сделанный для прослушивания офлайн: подкасты и музыка попадают в `~/Downloads` готовыми файлами с тегами, обложкой и главами.

> **Команда**: `udav` (**U**niversal **D**ownload **A**udio **V**ideo)

## Быстрый старт

```bash
# Зависимость (macOS)
brew install ffmpeg

# Установить команду глобально
npm install -g .

# Скачать аудио (режим по умолчанию)
udav "https://www.youtube.com/watch?v=dQw4w9WgXcQ"

# Скачать видео
udav "https://www.youtube.com/watch?v=dQw4w9WgXcQ" -v
```

Первый запуск скачивает yt-dlp (около 50 МБ, один раз) и занимает около минуты; дальше короткий трек качается за несколько секунд.

## Возможности

- 🎵 **Аудио по умолчанию**: M4A прямо из AAC-потока YouTube, без перекодирования и потери качества
- 🏷 **Готово для плееров**: название, исполнитель, дата и обложка встроены в файл; главы подкастов тоже (M4A, MP3)
- 🎬 **Видео, которое играет везде**: MP4 с H.264 + AAC (QuickTime, iPhone, телевизоры), до 1080p; `-q max` для 4K
- 📚 **Плейлисты**: ссылка на плейлист сохраняет все выпуски по порядку в отдельную папку
- 📁 **Умная организация файлов**: `~/Downloads/Audio/{сайт}/` и `~/Downloads/Video/{сайт}/`
- 🔄 **Не ломается со временем**: udav сам ставит yt-dlp и раз в день проверяет обновления; если YouTube что-то поменял, обновляет yt-dlp и пробует снова
- 🍪 **Cookies только когда нужно**: cookies браузера берутся, только если YouTube просит войти; cookies Safari отдаёт маленькое приложение-помощник, полный доступ к диску терминалу не нужен
- ⏯ **Докачка**: прерванная загрузка (Ctrl+C, пропала сеть) продолжается с того же места

## Установка

```bash
git clone <repository-url>
cd yt-downloader
npm install
npm install -g .   # по желанию: глобальная команда `udav`
```

### Требования

- **Node.js 22+**. udav ещё и передаёт его yt-dlp как JavaScript-движок, без которого YouTube сейчас не отдаёт видео.
- **FFmpeg** (извлечение аудио, склейка видео со звуком, обложки)
- **yt-dlp** на macOS ставится сам: живёт в `~/Library/Application Support/udav` (около 125 МБ), обновления проверяются раз в день. Python не нужен.

#### Установка FFmpeg

**macOS:**
```bash
brew install ffmpeg
```

**Linux:**
```bash
sudo apt install ffmpeg  # Ubuntu/Debian
sudo yum install ffmpeg  # CentOS/RHEL
```

**Windows:** скачать с https://ffmpeg.org/download.html

#### Linux и Windows

Автоматическое управление yt-dlp есть только на macOS. На других системах установите [yt-dlp](https://github.com/yt-dlp/yt-dlp#installation) так, чтобы он был в `PATH`. На любой системе `UDAV_YTDLP=/путь/к/yt-dlp` заставляет udav использовать указанный файл.

## Использование

### Базовое использование

```bash
# Скачать аудио (режим по умолчанию)
udav "URL"

# Скачать видео
udav "URL" -v

# Весь плейлист (выпуски по порядку, в отдельную папку)
udav "https://www.youtube.com/playlist?list=..."
```

Ссылка на трек внутри плейлиста или Микса YouTube (`watch?v=...&list=...`) скачивает только этот трек.

### Альтернатива для локальной разработки

```bash
npm run audio "URL"
npm run video "URL"
node src/cli.js "URL"        # аудио
node src/cli.js "URL" -v     # видео
```

### Расширенные возможности

```bash
# Подробный вывод для диагностики (IP-адреса замаскированы)
udav "URL" --verbose

# Своя папка (вместо умной организации)
udav "URL" -o ./downloads

# Название, автор и длительность перед скачиванием
udav "URL" -i

# Всегда брать cookies браузера (для приватных и платных видео)
udav "URL" -b safari

# Аудио в MP3
udav "URL" -f mp3

# Файлы поменьше: видео 720p или аудио с низким битрейтом (для речи хватает)
udav "URL" -v -q 720p
udav "URL" -q worst

# Обновить yt-dlp прямо сейчас
udav --update
```

## Организация файлов

```
~/Downloads/
├── Audio/
│   └── youtube/
│       ├── Название песни [video_id].m4a
│       └── Плейлист подкаста/
│           ├── 1 - Первый выпуск [id].m4a
│           └── 2 - Второй выпуск [id].m4a
└── Video/
    ├── youtube/
    │   └── Название видео [video_id].mp4
    └── vimeo/
        └── Видео [id].mp4
```

- **Аудио** (режим по умолчанию или `-a`) → `~/Downloads/Audio/{сайт}/`
- **Видео** (`-v`) → `~/Downloads/Video/{сайт}/`
- **Повторы**: уже скачанный файл повторно не качается
- Длинные названия сокращаются под ограничение macOS на длину имени файла (в том числе кириллические)

## Качество

### Видео (`-v`)

| `-q` | Результат |
|------|-----------|
| `best` (по умолчанию) | Лучшее MP4 с H.264 + AAC, обычно 1080p. Играет в QuickTime, на iPhone и телевизорах |
| `1080p`, `720p`, `480p`, `360p` | То же, с ограничением по высоте |
| `worst` | Самое маленькое MP4 |
| `max` | Максимальное разрешение в любом кодеке (4K AV1/VP9 в WebM/MKV): нужен VLC или IINA |

### Аудио

| `-f` | Результат |
|------|-----------|
| `m4a` (по умолчанию) | AAC с YouTube как есть, без перекодирования |
| `mp3` | Перекодирование в максимальном качестве MP3 (VBR V0) |
| `flac`, `wav` | Перекодирование (файлы больше, качество не выше исходного) |

`-q worst` выбирает самый лёгкий аудиопоток (на YouTube около 50 вместо 130 кбит/с): в 2,5 раза меньше, для речи хватает.

## Решение проблем

### YouTube "Sign in to confirm you're not a bot"

YouTube просит войти с некоторых адресов, чаще всего с адресов дата-центров (серверов VPN). udav сначала качает без cookies, а если YouTube просит войти, пробует ещё раз с вашими cookies YouTube.

**Safari (macOS).** macOS открывает cookies Safari только приложениям с полным доступом к диску. Если дать такой доступ терминалу, ваша почта, сообщения и cookies всех сайтов откроются любой программе, запущенной в нём. Поэтому udav использует маленькое приложение-помощник «udav Safari Cookies», и доступ получает только оно.

В первый раз, когда YouTube попросит войти, udav соберёт помощника из [`macos/safari-cookies`](macos/safari-cookies) (около 250 строк на Swift вместе с комментариями) компилятором Apple из Command Line Tools, подпишет его, откроет Системные настройки → Конфиденциальность и безопасность → Полный доступ к диску и покажет помощника в Finder. Перетащите «udav Safari Cookies» в список и включите (или нажмите +, затем ⇧⌘G и вставьте `~/Library/Application Support/udav`): udav это заметит и продолжит загрузку. Это делается один раз, потом помощник не пересобирается. Если udav скажет, что в Safari нет входа в YouTube, войдите в YouTube в Safari.

Когда YouTube просит войти, udav запускает помощника. Тот копирует только cookies youtube.com в `~/Library/Application Support/udav` (права 600), а udav удаляет копию после загрузки. У помощника нет аргументов, он пишет только в эту папку, не запускает других программ и подписан с hardened runtime, поэтому другие программы не могут внедрить в него свой код. Но любая программа под вашим пользователем может запустить его и получить ваши cookies YouTube: в худшем случае утечёт сессия YouTube, а не весь диск.

**Chrome, Edge, Firefox.** С macOS 27 терминал без полного доступа к диску вообще не может прочитать их данные, и udav прямо об этом говорит. Там, где yt-dlp может прочитать Chrome или Edge, macOS спросит пароль связки ключей: нажмите «Разрешить». «Всегда разрешать» открывает эти cookies любой программе без вопросов.

**cookies.txt.** `-c cookies.txt` работает с файлом, выгруженным из любого браузера.

**Через VPN?** Поможет другой сервер, если он у вас есть.

### «YouTube что-то поменял»

Ошибки вроде "Requested format is not available" или "HTTP Error 403" обычно значат, что YouTube что-то поменял. Тогда udav проверяет, нет ли свежей yt-dlp, ставит её и пробует снова. Если у вас уже последняя версия, исправление обычно выходит в течение нескольких дней; `udav --update` поставит его сразу.

### Проблемы с сетью

"Network problem" значит, что сайт недоступен: проверьте интернет или VPN. Прерванная загрузка продолжится, если запустить ту же команду ещё раз.

### macOS спрашивает про папку «Загрузки»

При первом скачивании macOS может спросить, разрешить ли терминалу доступ к папке «Загрузки»: разрешите. Если раньше отказали: Системные настройки → Конфиденциальность и безопасность → Файлы и папки.

### URL со специальными символами

Всегда берите URL в кавычки:

```bash
udav "https://www.youtube.com/watch?v=dQw4w9WgXcQ&list=PL123"   # работает
udav https://www.youtube.com/watch?v=dQw4w9WgXcQ&list=PL123     # ошибка в zsh
```

## Справочник команд

- `-a, --audio` - Только аудио (режим по умолчанию)
- `-v, --video` - Скачать видео
- `-o, --output <dir>` - Своя папка (по умолчанию: `~/Downloads/Audio|Video/{сайт}/`)
- `-f, --format <format>` - Формат аудио: `mp3|m4a|wav|flac` (по умолчанию: `m4a`)
- `-q, --quality <quality>` - Видео: `best|max|worst|1080p|720p|480p|360p`; аудио: `best|worst` (по умолчанию: `best`)
- `-i, --info` - Показать название, автора и длительность перед скачиванием
- `-b, --browser <browser>` - Всегда брать cookies этого браузера: `chrome|firefox|safari|edge`
- `-c, --cookies <file>` - Путь к файлу cookies.txt
- `-U, --update` - Обновить yt-dlp сейчас (и так проверяется раз в день)
- `--verbose` - Подробный вывод yt-dlp
- `-h, --help` - Справка
